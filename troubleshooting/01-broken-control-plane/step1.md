#  Broken Control Plane

## Troubleshoot the Incident

A production Kubernetes environment is having an outage. You have admin access to the control-plane node.

Something is wrong with the cluster — and it's not just one issue.

## Your Task

Investigate and restore normal operation. There's an application running in the `dragon-app` namespace that isn't behaving correctly. You need to figure out:

* Why API operations are failing.
* Why a workload in `dragon-app` can't get scheduled.
* What's stopping the cluster from working normally.
* How to fix it safely without rebuilding or using shortcuts.

## Success

The challenge is done when the final validation passes.

You're expected to investigate and figure it out yourself — no individual hints in this step.
